Quickstart Guide

Booting the Web UI

How to access your study system's web interface from your laptop.

Prerequisites

  • VM is running (systemd keeps it alive 24/7)
  • SSH key for your server
  • PowerShell or any terminal on your Windows laptop

Connect

1
Open PowerShell

Press Win + X → Terminal, or search "PowerShell" in Start.

2
Start the SSH tunnel

This forwards the VM's port 3000 to your laptop. Paste and run:

ssh -L 3000:localhost:3000 -i "<path-to-your-ssh-key>" <your-username>@<your-server-ip>
3
Open the web UI

In your browser, go to:

http://localhost:3000

That's it. You can now upload material, generate questions, review and approve them. The Telegram bot picks them up automatically.

When You're Done

→
Close the tunnel

Go back to PowerShell and press Ctrl + C, or just close the window. The Telegram bot keeps running on the VM regardless.

Troubleshooting

"Connection refused" in browser

The service might have stopped. SSH into the VM and restart it:

sudo systemctl restart study-bot sudo systemctl status study-bot
"Address already in use" on laptop

You have another tunnel open. Close all PowerShell windows and try again.

Check live logs
sudo journalctl -u study-bot -f
